# Werkbank

Persoonlijke werkcockpit voor dagelijks schoolwerk: taken, snelle dumps, ICT-meldingen en snelkoppelingen in één installeerbare PWA.

## V0.1
- Dashboard met dagoverzicht
- Snelle Dump die losse regels omzet in taken
- Taken met categorie, prioriteit, deadline en status
- ICT-meldingen met statusflow
- Bewerkbare snelkoppelingen
- Lokale opslag in de browser
- Export/import van Werkbank-data als JSON
- Offline PWA met service worker

## Publiceren via GitHub Pages
Zet in **Settings → Pages** bij *Build and deployment* de bron op **Deploy from a branch**, kies `main` en `/ (root)`.

> V0.1 bewaart gegevens alleen op het apparaat in `localStorage`. Voor synchronisatie tussen apparaten kan later een backend worden toegevoegd.
